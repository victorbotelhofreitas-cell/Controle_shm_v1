          Export Snap Notion
          
Cria uma subpágina nova (histórico, nunca sobrescreve) dentro de "Controle SHM / Registro de Snaps" no Notion, com uma foto do Board Jira de agora.

          
          

          

            
            Controle SHM / Registro de Snaps (Notion)
          

          

            
          

          

            
    
              
  1. Clique em Export Snap Notion — roda direto aqui no site (chama o backend, que fala com o Jira e com o Notion).
    2. 
              
  2. Espera terminar (alguns segundos) — a mensagem abaixo do botão confirma sucesso ou mostra o erro.
    3. 
              
  3. Quando der certo, aparece um link "Abrir página no Notion" levando direto pro snap recém-criado.
    4. 
              
  4. Para ver o histórico completo de snaps já gerados, use o link "Controle SHM / Registro de Snaps" logo acima.
    5. 
            

          

        


        

          Sincronizar Gravações BotDesign
          
Busca no Gmail (marcador # SHM) os vídeos de reunião gravados pela Alana via tl;dv e adiciona no Notion "BotDesign (Gravações)" só os que ainda não estão lá.

          
          

          

            
            BotDesign (Gravações) (Notion)
          

          

            
          

          

            
    
              
  1. Clique em Sincronizar Gravações BotDesign — roda direto aqui no site (o backend precisa ter o Gmail configurado, ver github-README.md).
    2. 
              
  2. Espera terminar (alguns segundos) — a mensagem abaixo do botão mostra quantos vídeos novos foram adicionados, ou que já estava tudo sincronizado.
    3. 
              
  3. Use o link "BotDesign (Gravações)" acima para abrir a página no Notion e conferir.
    4. 
              
  4. Se aparecer erro de "GMAIL_REFRESH_TOKEN não configurado", siga o passo a passo em github-README.md seção "Configurar Gmail".
    5.
